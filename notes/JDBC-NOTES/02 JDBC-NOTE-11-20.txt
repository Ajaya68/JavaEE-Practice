ResultSet:
==========
    -ResultSet is an object used to store and retrieve the data returned by a SQL query. 
    -When we execute a SELECT statement using a Statement or PreparedStatement, 
     the database returns the result in the form of a ResultSet.
    -ReasultSet object will maintain a cursor which will point to current row.
    -initially ResultSet cursor will point before first row. we need to move the cursor
     to next position by calling next() method.
    
Important ResultSet Methods
=============================
Method	            Purpose
======              ========
boolean next()      Moves the cursor to the next row
int getInt()        Retrieves an integer value
String getString()	Retrieves a string value
double getDouble()	Retrieves a double value
getDate()	        Retrieves a SQL date
getObject()	        Retrieves a value as an Object
wasNull()	        Checks whether the last retrieved value was SQL NULL
close()	            Closes the ResultSet

ResultSet Cursor
==================
    -When a ResultSet is created, its cursor is initially positioned before the first row.

        while (rs.next()) {
            System.out.println(rs.getString("name"));
        }

    -Each call to next() moves the cursor to the next row.

PreparedStatement Interface:
============================
    -PreparedStatement is an interface in JDBC used to execute precompiled, parameterized 
     SQL statements. 
    -It uses ? placeholders for dynamic values and provides setXXX() methods to assign 
     values to those parameters. 
    -It can be used for SELECT, INSERT, UPDATE, and DELETE operations and helps prevent 
     SQL injection.
    
Why do we use PreparedStatement?
=================================
    -Suppose we want to insert student data.

Using Statement:

    String sql = "insert into student values(101, 'Ajaya', 85)";
    Statement stmt = con.createStatement();
    stmt.executeUpdate(sql);

Here, the values are directly written into the SQL string.
With PreparedStatement:

String sql = "insert into student values(?,?,?)";
PreparedStatement pstmt = con.prepareStatement(sql);
pstmt.setInt(1, 101);
pstmt.setString(2, "Ajaya");
pstmt.setInt(3, 85);
pstmt.executeUpdate();

This is cleaner and safer.

Creating PreparedStatement
==========================
    -We create a PreparedStatement using the Connection object:

    PreparedStatement pstmt = con.prepareStatement("insert into student values(?,?,?)");

    -The ? symbols are called parameter placeholders.

For example:
============
insert into student values(?,?,?)

means:

       ?       ?       ?
       ↓       ↓       ↓
    rollno    name    marks

Setting values
===============
    -We use setXXX() methods to provide values for the placeholders.

    pstmt.setInt(1, 101);
    pstmt.setString(2, "Ajaya");
    pstmt.setInt(3, 85);

    -The first argument represents the parameter position.
        1 → first ?
        2 → second ?
        3 → third ?

So:
pstmt.setInt(1, 101);
means:
First ? = 101
And:
pstmt.setString(2, "Ajaya");
means:
Second ? = "Ajaya"

Important set methods
=====================
Some commonly used methods are:

Method	        Used for
======          ==========
setInt()	    NUMBER / integer
setString()	    VARCHAR2 / String
setDouble()	    Decimal values
setFloat()	    Float values
setLong()	    Long values
setDate()	    SQL date
setBoolean()    Boolean
setNull()	    SQL NULL
setObject()	    General Java object

Example:

pstmt.setInt(1, 101);
pstmt.setString(2, "Ajaya");
pstmt.setDouble(3, 85.5);
